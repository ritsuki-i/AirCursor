Control,without touch.

触れずに、操る。

Add touchless interaction to the web product you already ship. AirCursor turns webcam hand tracking into standards-based pointer events, so kiosks, installations, demos, and web apps gain gesture control without a custom interaction layer. Processing stays on-device.

既存のWebプロダクトに、非接触のインタラクションを追加。AirCursorは手の動きを標準的なポインターイベントへ変換し、キオスク、展示、デモ、Webアプリを独自の操作レイヤーなしでジェスチャー対応にします。映像処理は端末内で完結します。

npm install air-cursor

Gestures

Five gestures. Two hands.5つの操作。2つの手。

RIGHT HAND右手

Pointerポインター

Join your index and middle fingertips. Move your hand to point.人差し指と中指の先を合わせ、手を動かしてポインターを操作します。

RIGHT HAND右手

Click & dragクリック・ドラッグ

From Pointer, bring in your thumb to click. Keep the three fingertips together to drag.ポインター状態から親指を合わせてクリック。3本を合わせたまま動かすとドラッグします。

RIGHT HAND右手

Grab & scrollつかんでスクロール

Pinch thumb and index only, keeping the other fingers apart. Move to scroll the page.他の指を離したまま親指と人差し指だけをつまみ、手を動かしてスクロールします。

LEFT + RIGHT HAND左手＋右手

Select a screenshot areaスクリーンショット範囲を選択

Meet both pinches at one point, then spread to opposite corners. Open both hands to freeze the green area, then pinch once with each hand to capture it.両手のつまみを一点で合わせ、対角方向へ広げます。両手を開いて緑の範囲を固定し、左右それぞれでもう一度つまむとスクリーンショットを撮影します。

LEFT + RIGHT HAND左手＋右手

Right click modifier右クリック修飾

Hold your left hand in a fist, then click with your right hand. The click becomes a right click.左手を握ったまま右手でクリックすると、右クリックとして送出されます。

    Install

    Ship it in three lines.

    The component renders a start button and handles the consent step and camera preview. Once a visitor grants access, the rest of your page becomes operable by hand — you change nothing else. 

    // React
import AirCursor from 'air-cursor';

export default function App() {
  return <AirCursor />;
}

    The engine has no React dependency, so plain JavaScript, Vue and Svelte are all first-class. The individual pieces — VirtualPointer, GrabScroller, TwoHandRecognizer, OneEuroFilter — are exported too, if you want your own mapping. 

    // anything else
import { AirCursorEngine } from 'air-cursor';

const engine = new AirCursorEngine({
  video: document.querySelector('video'),
  onState: (s) => console.log(s?.mode),
});
await engine.start();

    Built for your web stack

    Real pointer events. No custom interaction layer.

    Most webcam gesture libraries find an element with elementFromPoint and dispatch a single click. That covers buttons and links and nothing else. AirCursor synthesizes what a real pointing device produces, so behaviour that depends on the sequence works — including in Radix, MUI and every pointer-based drag library, which listen on pointerdown rather than click.

    InteractionEvents emitted
    Hoverpointerout → pointerleave → pointerover → pointerenter
    Movepointermove, mousemove
    Clickpointerdown → mousedown → pointerup → mouseup → click
    Right clickpointerdown{button:2} → pointerup → contextmenu
    Dragpointerdown → pointermove… → pointerup, captured to the press target

    Steady enough to aim with

    Pointer position runs through a One Euro filter, which smooths hard when the hand is still and barely at all when it moves fast. Gesture booleans use separate enter and exit thresholds plus a hold window, so a hand resting on a threshold cannot chatter and poses passing through on the way somewhere else do not fire.

    Every threshold is measured in hand units — wrist to middle-finger knuckle — so a gesture reads the same close to the camera or across the room.

    Smooth even when tracking stutters

    Inference and actuation are separated. MediaPipe runs at whatever rate the CPU allows and that rate fluctuates; scrolling, cursor movement and physics run on requestAnimationFrame instead.

    The field behind the hero is the same readout, not a separate scene — which is why it does not fight the model for the frame.

    Known limits

    What a synthetic pointer cannot do.

    These are properties of the browser platform, not gaps waiting to be filled. They are listed here rather than discovered later.

    • Double click is out of reach by hand. A click only registers once the pose has been held long enough not to be a thumb passing through, and two of those cannot fit inside the window a browser counts as a double click. Bind anything that would need one to a single click instead.
    • No user activation. Synthetic events carry isTrusted: false, so anything gated behind a real gesture stays out of reach: clipboard reads, requestFullscreen(), window.open(). Clipboard writes generally succeed in Chrome, but not in Firefox or Safari.
    • CSS :hover does not respond. Hover styling comes from the browser's own hit testing. JavaScript hover handlers fire correctly; :hover rules do not. AirCursor adds an aircursor-hover class to the element under the cursor, so style that alongside it.
    • Native HTML5 drag-and-drop does not start. draggable="true" only responds to trusted input. Pointer-event based drag libraries work normally.
    • The model is fetched from a CDN by default. Point mediapipeBasePath at a self-hosted copy for offline or kiosk installations.
